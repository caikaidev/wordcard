# 拾句复习体验：以独立回忆为核心（v1）

参考：词光 Word Atlas 的 [学习流程](https://github.com/designfuchen/word-atlas/blob/main/src/store/session.ts) 与 [FSRS 评分](https://github.com/designfuchen/word-atlas/blob/main/docs/learning-model.md)。保留拾句的「文章 → 真实表达 → AI 批改 → 复习」路线，不引入预设词库或额外游戏入口。

## 已实现：让复习评分反映第一次独立回忆

**正式复习**：正面先回想，翻开答案后选择「忘了 / 模糊 / 记得」。认读或产出题使用「提示首字母」后，本次不能再选「记得」；不使用提示则保持原评分规则。键盘快捷键受同一限制，避免绕过按钮禁用状态。

**本轮错题巩固**：首次点「忘了」时，服务端记录遗忘并安排 10 分钟后的复习；该卡继续排到本轮末尾，作为一次**不计分的巩固**。巩固阶段仅需回忆并点击「完成巩固，继续」，不会对同一张卡再次调用评分接口，不会因临时想起来而将 10 分钟复习覆盖成几天后。这也避免一次忘记被重复计入今日统计。

**清楚的反馈**：在提示后的评分区域显示原因；在巩固阶段告诉用户这次不会修改复习日期。卡片切换、跳过、恢复跳过卡片时，清空提示状态。

### 验收点
- 认读/未使用提示的产出题：仍允许三档评分，保存一次。
- 产出或语境正面点「提示首字母」：翻背后「记得」禁用，键盘 3 也不发送评分；「忘了」「模糊」可用。
- 正式复习点「忘了」：首次发送一次评分请求；队尾重见该卡，无论是否提示都不能再修改服务端的 SRS 记忆状态；可完成巩固。
- 切换到下一张卡：提示限制不会串到下一张。
- 原有每批 20 张、跳过、标记 DONE、移动端滑动和复习模式保持不变。

## 下一阶段（未实现）

1. **首答质量统计**：同时显示本轮首答正确率、提示率和巩固卡数量。分母应为实际作答的唯一卡片数，重练不计入。
2. **渐进式提示**：首字母提示之外可提供词长、语境释义，但所有提示共享同一受限评分规则，不泄露答案后仍算记得。
3. **FSRS 迁移验证**：先保留当前 `interval / due_at / reps / lapses` 数据及用户评级，再新增事件日志与稳定度等字段；在影子模式比较新旧调度效果与复习负担。**不能仅替换 `shared/srs.ts` 的乘数算法就声称实现 FSRS**：需要历史记录、参数校准、版本化迁移和新用户冷启动策略。
4. **学习路径整合**：在「练习」完成页聚合本次写作中加入的词句，并清楚引导下一步的主动回忆；不增加独立的「词光式」词库导航。
