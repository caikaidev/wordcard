# 复习预测与卡片点词查义（PR #17）

## 设计边界

- **未来 7 天**：以北京时间 UTC+8 的自然日为单位，从今天至第七天（含）显示仍在学习中的词条的到期量。今日包含此前已逾期以及今天稍晚到期的卡片；已完成（DONE）的卡片和其他用户的卡片不计入。
- **预测不是承诺**：这是当前 `due_at` 排程的快照。学习、遗忘、标记 DONE 或新加入卡片后，数量会改变。它不调用 AI，也不写入记忆排程。
- **例句点词**：只有翻开复习卡片后才可点击英文例句中的词。字典查询沿用原文阅读页的 `/api/lookup`（不生成 AI 内容）。用户主动点「加入复习」才走 AI 补全，保留原句语境。
- **不修改首次评分**：沿用已合并 PR #16 的首次记忆评分和服务端防重复评分。弹层打开时不执行复习快捷键，手机弹层的触摸事件也不会冒泡到背后的左滑跳过手势。

## 数据与 API

`GET /api/review/forecast` 返回 `start`（北京时间当天零点对应的 UTC 毫秒时间戳）、七个按日排序的 `{ date, count }` 和 `total`。

SQL 在数据库内按 `due_at` 分桶，不读取全部词条，也没有 500 条分页限制。所有分桶在用户范围内聚合且仅取 `active` 状态；跨日边界按北京时间，不依赖手机系统时区。首次进入「每周回顾」当前周时读取；切换到历史周时不显示预测。

## 手动验收（尤其 iPhone Safari）

1. 打开复习页，查看「未来 7 天」入口是否在窄屏与桌面端都可见。
2. 打开「每周回顾」，查看每一天的计数以及「今天」的逾期包含规则；空词库应显示七个 0，切换到上周时不显示预测。
3. 翻开有例句的卡片，点按任一英文单词，查看字典弹层；弹层内上下滚动和横向触摸，不应使底层卡片跳过。关闭后仍是原卡片且不会改变评分。
4. 键盘操作：弹层打开时 1/2/3、空格不会触发背后复习操作；关闭后继续正常。
5. 从原文阅读器点词、长按选中短语、加入复习应与原有行为一致。
6. 词典或网络调用失败时可关闭弹层继续复习；免费文本引擎的选择和 MeloTTS 发音不受此功能影响。
